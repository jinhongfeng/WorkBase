# WorkBase 本轮实现报告（P1: 可用化 + 视觉重做）

> 承接 `docs/DESIGN.md`。本轮目标：把 P0 的空壳做成可用产品，并加入雅思学习、完整笔记、推荐工具与视觉体系。

## 一、交付范围

### 1. 笔记（完整实现）

- 三栏结构：列表 / 编辑器 / 大纲与信息。
- 富文本实时编辑（Tiptap 3）：标题、加粗、斜体、删除线、下划线、行内代码、引用、有序/无序/任务列表、分隔线、图片。
- 双模式：富文本 ⇄ Markdown 源码。富文本写入时经 turndown 转 Markdown 存储，读取时经 marked + DOMPurify 转回，Markdown 始终是唯一事实来源。
- 图片：粘贴或拖拽即上传到本地 `files/images/`，通过自定义协议 `wb-asset://` 显示；不经过网络。
- 日记：`kind = 'journal'` + `journal_date` 唯一索引，同一天重复创建会打开已有日记而不是覆盖（已修）。
- 自动保存（900ms 防抖）+ Ctrl S 手动保存，底部状态条显示保存态与字数。
- 全文搜索（标题/正文/标签 LIKE）、置顶、删除确认、大纲跳转。

### 2. 雅思学习（新增）

- 表单：主题（含 6 个快捷主题）、目标分 6.0/6.5/7.0+、数量 6–16、类型 单词/句型/混合。
- AI 生成：主进程构造教学 Prompt，要求严格 JSON；`extractJson` 容忍代码围栏与前后说明；Zod 二次校验后入库。
- 卡片库：词性/音标/释义/例句（目标词高亮）/翻译/高分搭配/分数段/掌握度点阵/朗读（Web Speech）。
- 复习：闪卡翻转 + 认识/不认识，掌握度 0–6 与间隔（6 小时 → 16 天）动态调整，复习记录单独入表用于连续天数统计。
- 未配置 API Key 时：页面顶部引导条 + 生成按钮禁用并跳设置，不报错。
- 删除学习包（确认后级联删除词条与复习记录）。

### 3. 推荐工具（新增）

- **专注**：25/45/60 分钟番茄钟、环形进度、完成自动入库、最近 7 天柱状趋势。
- **习惯**：14 天打卡网格（可补打卡）、连续天数、emoji 图标、删除。
- 待办：从占位变为可用（优先级、截止日期、逾期标记、分组、清理已完成、今日进度）。
- 智能助手：流式输出（SSE 增量经 IPC 推送到渲染层）、快捷提问、整轮对话存为笔记。

### 4. 视觉体系重做

- **背景层**：网格线（径向遮罩淡出）+ 三团模糊光晕（缓慢漂移）+ 噪点纹理，随主题切换强度。
- **异形框**：`.shape-a/-b/-c` 不对称圆角、`.notch` 切角、`.bracket` 四角角标，用于首页、学习卡、专注台、统计块。
- **排版**：`--font-display`（Georgia + 中文回退）承担大标题与数字，等宽字体承担元信息。
- **首页 Bento**：8+4+4+5+4+3 的非对称网格；深松绿 Hero、环形学习进度、周专注柱、常用入口、今日待办、笔记指标、今日一记。
- **暗色**：完整深松墨配色（非简单反色），阴影与光晕单独调参。
- 全部动效遵循 `prefers-reduced-motion`。

### 5. 数据与安全

- 迁移 002/003/004：笔记类型与日记唯一索引、`secrets` 表、雅思三表、习惯/打卡/专注表。
- AI Key 经 `safeStorage` 加密存储（Windows DPAPI），未加密可用时直接报错而非明文降级。
- 新增自定义协议 `wb-asset://`，解析时拒绝越出 `files/` 的路径。
- 所有新 IPC 通道使用 Zod 校验参数；CSP 收紧到 `img-src 'self' data: blob: wb-asset:`。
- 设置页支持导出 `.db` 备份（导出前 WAL checkpoint）与打开数据目录。

### 6. 导航与可插拔

- 模块仍由 `features/*/module.tsx` 编译期 glob 自动发现；新增 `hidden` 字段用于隐藏未接入模块。
- 未接入的邮件、支付宝账单、数据源暂时隐藏（`hidden: true`），代码保留待 P2 接入 IMAP 后开放。
- 命令面板升级为「功能 + 笔记全文」联合搜索，选中笔记直接跳转并打开。

## 三、已知风险

1. **未做真实邮箱/AI 联调**：AI 生成链路需要真实 Key 才能端到端验证；当前仅验证了未配置态的引导与请求结构。
2. **Tiptap 往返有损**：Markdown → HTML → 编辑 → Markdown 的往返会丢失部分原文格式细节（如自定义表格对齐、HTML 注释）。正文语义不受影响。
3. **演讲稿依赖系统语音**：`speechSynthesis` 的可用音色取决于操作系统，未安装英文语音时朗读可能静默失败。
4. **一次性大量生成**：AI 返回条数超出请求时按 `count × 2` 截断，避免单次写库过大；超长文本按字段长度截断。
5. **打包体积**：包含 Chromium 与 better-sqlite3，安装包预计 100MB 级别。
