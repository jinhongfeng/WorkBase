本轮打包包含首页月历悬停详情、待办独立双栏卡片、智能助手说明精简和此前的组件更新。`pnpm dist` 完成 Windows x64 构建与原生模块重建。解出的安装版程序和免安装版均在独立数据目录启动，验证待办写入、双栏布局和 SQLite `quick_check`。用同一已验证程序重新封装后，安装包内的程序和资源校验一致，免安装版通过重启读回。两份发布包已覆盖原文件并核对 SHA-256。旧的 `win-unpacked` 中 `app.asar` 被 WorkBuddy 占用，正式交付以本表两份 EXE 为准。

上轮重打包包含壁纸按方向自动排版和专注页卡片等高两项更新。`pnpm typecheck`、`pnpm lint` 和 `pnpm dist` 通过。安装包静默安装和卸载成功，安装版和免安装版均在独立数据目录进入首页、通过 SQLite `quick_check`，并验证横图铺满、竖图完整显示和专注卡片等高。下方保留首次发布候选版的验收记录。

## 验收范围

| 项目 | 结果 |
| --- | --- |
| 启动与窗口 | 新装后进入首页实测 1.51 秒，浅色和深色启动动画约 0.69 秒。系统开启减少动态效果后直接进入工作台。模拟失效的外接屏坐标，窗口能回到主屏。空库四进程的私有工作集为 141 MiB，计入共享页的进程工作集直接相加为 406 MiB。免安装包还需解压，本机首次进入首页实测 7.37 秒。 |
| 导航与界面 | 11 个可见页面在 1080×700 和 1360×860 下完成扫描。独立环境抽查五页的两档尺寸、深浅主题和 76 次控件命中。增加一个模块文件后，入口自动出现在更多、快速跳转、首页常用编辑区，并可固定、重启保留和直接进入。删除文件后入口自动消失。 |
| 数据保存 | 测试自动保存请求进行中继续输入并切页、同日创建日记、删除后的迟到保存、立即退出、保存错误返回编辑，以及迁移或重启前写盘。10,000 条笔记分页样本可跳到第 100 页并打开最早记录，尾页读取实测 7.4 毫秒。 |
| 数据兼容 | 测试自建 007 版本数据库升级到 011，笔记、旧账单、Skill、旧壁纸保留。测试新旧账单去重、错误 ZIP 密码、非法 ZIP 路径和迁移、备份及附件校验。 |
| AI 与媒体 | 用本机兼容接口验证 AI 配置、流式对话、长历史继续聊天、无密钥连接和旧密钥移除。雅思生成、复习和删除通过。测试本地和链接 WebM、GIF 保留、范围读取和媒体操作失败回滚。验证 Skill 的目录、Markdown、ZIP 导入、置顶和 GIF 封面。 |
| 专注 | 切换场景、退出沉浸及切页后继续计时。结束只保存一条记录，专注趋势刷新。 |

`pnpm typecheck`、`pnpm lint`、`pnpm build`、`pnpm dist --config.directories.output=release/1.0.0-rc.1`、冻结锁文件检查与 `git diff --check` 均通过。打包时重新构建了 better-sqlite3。NSIS 静默安装和卸载均成功。安装版、免安装版均通过首次建库、首页快速记录、重启后笔记和四个常用入口留存，两个测试数据库的 `PRAGMA quick_check` 均返回 `ok`。构建日志含第三方库的 `use client` 打包提示。

## 尚待确认

- 使用真实 QQ 邮箱获取支付宝附件、使用真实 AI 供应商，以及手动操作 Windows 系统壁纸和原生文件选择器尚未验收。对应集成测试使用本地服务、样本文件或向原生选择器提供固定测试路径。
- Windows 强制关机及系统终止进程的笔记保存尚未验证。普通关闭、托盘彻底退出和应用重启走退出保存流程。
- 设计文档对隐藏模块路由、失效 pin 的存储和年度活动是否计入专注有冲突。当前按既有界面口径保留隐藏边界、忽略失效入口，专注分钟在专注趋势中呈现。智能助手上下文入口尚未开放。详见 `temp/blocker.md`。
- 当前环境未配置代码签名证书。
- 自动审批以 `blocked by policy` 拒绝递归清理隔离测试目录。部分测试构建与样本留在项目的 `temp/`，发行包的文件清单已经单独检查。
