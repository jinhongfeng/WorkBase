# WorkBase 界面检查

2026 年 11 月 15 日。依据当前源码和《设计规范》，在独立桌面实例里检查 15 个可见模块。使用实际的 1360×860 和 1080×700 窗口，补查了空状态、长内容、常用弹窗、四种风格的浅深色组合，以及清晰背景。邮件、数据源和演示模块按现有设计隐藏。

## 优先处理

1. **媒体库搜索让用户误以为素材不存在。** 复现时把图片放入一个分组，在媒体库首页搜索图片的完整名称。首页显示「没有匹配的素材」，进入分组后保留同一个搜索词，马上显示该图片。首页搜索建议默认覆盖分组内素材，并在结果上标出所属分组。若产品决定保留现有搜索范围，应使用「搜索未分组素材」和对应的空状态文案。 [首页结果](../temp/ui-audit-20261115/evidence/detail-media-search.png) · [组内结果](../temp/ui-audit-20261115/evidence/detail-media-search-inside.png) · [查询与空状态](../src/renderer/src/features/media/MediaPage.tsx#L78)
2. **专注页把近 7 天写成「本周」。** 同一个合计在右侧统计卡和下方说明各出现一次，底层取今天及此前 6 天，跨周时会把上周的数据算进「本周」。统一为「近 7 天」，把日均移到相邻图表的说明中。 [统计页面](../src/renderer/src/features/focus/module.tsx#L167) · [统计口径](../src/main/db/repo/growth.ts#L98)
3. **首页可同时进入「编辑常用」和「管理卡片」。** 1080×700 时，常用工具条、两个添加区域和卡片上的拖动控件一起抢占首屏。常用调整即时保存，卡片调整有「取消」「完成」。两个操作的保存时机难以从界面判断。先让两个编辑状态互斥，分别说明是否即时保存。 [同时开启的界面](../temp/ui-audit-20261115/evidence/detail-dashboard-both-edit.png) · [保存方式](../src/renderer/src/features/dashboard/module.tsx#L179)
4. **苹果深色风格的侧栏数字偏淡。** 默认强调色下，非选中项的 10px 白色数字与蓝底实测对比度约 3.65∶1，低于小字的 4.5∶1 对比目标。修正角标的前景或底色，然后复测各风格的默认及自定义主题色。开启「清晰背景」时，首页问候、常用入口和导航图标直接压在高反差壁纸上，还需检查这些区域的独立底色。 [角标样式](../src/renderer/src/styles/layout.css#L220) · [苹果风格色值](../src/renderer/src/styles/tokens.css#L237) · [壁纸样本](../temp/ui-audit-20261115/evidence/detail-wallpaper-clear-dashboard.png)

| 界面 | 检查结果与建议 |
| --- | --- |
| 全局导航 | 两档窗口正常切换文字侧栏与图标轨，标题栏搜索保留可点击区域。「更多」负责浏览和固定功能，命令面板支持快速动作和笔记搜索，两者的任务不同。让「全部功能」里的首页、助手、设置明确显示为固定入口，插件目录操作继续放在面板底部。 |
| 首页 | 默认首屏先看到四张统计卡，快速记录位于其下。若首页主要用来开始当天工作，建议把快速记录和今日待办提到统计前，现有统计可保留在后面。「快速记录」保存普通笔记，「今日一记」编辑当日日记，两条记录路径有区别。 |
| 笔记 | 同一个标题出现在顶栏、正文输入框和大纲根节点，另有左侧选中项。可让正文标题承担命名，顶栏留给模式和文档操作。切到 Markdown 后，大纲仍占一列，测试文档的 12 个标题链接全部禁用。可让它跳到源码对应行，或在该模式默认收起。1080×700、记住较宽的两栏时，编辑区收至 424px，工具栏换行，操作仍可见。 [Markdown 状态](../temp/ui-audit-20261115/evidence/detail-notes-markdown.png) · [大纲实现](../src/renderer/src/features/notes/module.tsx#L365) |
| 待办 | 「全部」视图已经带已完成列，还有独立「已完成」筛选。完成项很多时，建议在「全部」视图折叠已完成列或只预览少量，完整历史与「清除已完成」放在已完成视图。实测可从任务行打开编辑。先统一「今日与逾期」「今天与逾期」的叫法。 |
| 习惯 | 新建表单将图标、颜色、每日目标全部常驻在打卡表上方，常用的打卡区域首屏空间有限。可以只常驻名称和添加，把默认图标、颜色、目标放进「更多选项」。计数型习惯点满后再点会直接归零，建议让重置动作更明确。 [打卡逻辑](../src/renderer/src/features/habits/module.tsx#L74) |
| 专注与沉浸 | 工作台可选时长、填写主题并启动。沉浸页的「控制」内同屏承载计时、场景和空间设置，暂停和返回工作台需要先展开。可把常用的暂停／继续和返回留在底栏，把场景、背景和氛围继续放在面板内。 [控制面板](../temp/ui-audit-20261115/evidence/detail-immersive-controls.png) |
| 英语 | 学习库、复习和报道阅读的任务不同。学习库同时摆全库统计、学习包下拉、词条类型与待复习筛选，进入精读包仍显示「已掌握几条」。建议突出当前学习包和下一步，将「单词／句型」与「待复习」明确为类型和状态。精读阶段的正文和揭示后内容已打开检查。 [精读页](../temp/ui-audit-20261115/evidence/detail-ielts-reading-reveal.png) |
| 账单 | 本月数字与范围数字挨着展示，时间切换只改后者和图表。给右侧小组加明示的范围标题，保留两组统计。交易明细展开后有独立搜索和收支筛选，建议加短标签「筛选明细」，让用户知道上方图表口径保持原样。 [明细视图](../temp/ui-audit-20261115/evidence/detail-bills-table.png) |
| 每日简报 | 默认折叠有助于扫读日期。顶部「上次同步」与每期「最近获取」同屏，同批同步时每一行重复日期。可以在展开时再显示获取时间，折叠行突出期号，保留来源链接。 |
| 媒体库 | 批量管理时分组卡仍可点击，进入分组会退出批量状态并清空选择。建议批量状态只显示可勾选素材，或明确分组是切换范围的入口。加素材、分组操作、批量操作各自有用途。 |
| Skill 库 | 列表已能按来源筛选，详情也有预览、编辑、文件三个用途。列表右侧的来源与时间、详情顶部的来源和更新时间可以按浏览场景取舍。优先统一笔记与 Skill 的列表标题、搜索、筛选顺序和文件夹管理入口。 |
| 时间线 | 年份索引和照片网格在两档均可显示。工具栏「条记录」跟随搜索和年份，照片、日期、年份数按全库统计，四个数并排容易被理解为同一范围。建议把当前结果计数放到筛选旁，其余统一标为全库统计。 [统计显示](../src/renderer/src/features/memories/MemoriesPage.tsx#L97) · [查询口径](../src/main/db/repo/memories.ts#L41) |
| 密码库 | 有 12 个账号时，只能靠长列表找账号，「浏览器连接」被推到列表下方。页头宜保留添加和锁定，账号列表增加按站点或用户名定位，浏览器连接给一个可见的状态入口。手动刷新在浏览器可能新增账号时有用途，收起它之前需有自动刷新。 |
| 智能助手 | 对话正文、会话列表和输入框三处尺寸都可调，两个聊天区手柄调的是同一宽度。建议默认只显会话分隔线，其他手柄在相关区域悬停或聚焦时可见。整段保存到笔记、单条回复复制、代码块复制的作用范围不同。会话右键和页头操作菜单各覆盖不同的使用路径。 [现有会话](../temp/ui-audit-20261115/evidence/detail-ai-chat.png) |
| 自媒体写作 | 直接写文章和参考创作是两条工作流。参考创作首屏同时出现素材领域、素材来源和后续拆解区，未添加素材就已面对第二个大表单。建议选素材后再突出拆解，选择角度后再展开观点、正文／分镜选项。手动粘贴后保留一处编辑入口，让用户能看见已加入几条。 |
| 设置 | 四个页签边界清楚。外观页一列叠放主题、界面风格、主题色和壁纸，窄窗要在面板内滚动才能到达壁纸。建议在外观内先呈现界面样式和壁纸两组入口。数据路径已在「数据与备份」展示，「关于与快捷键」只需留打开对应设置的链接。 [最小窗口](../temp/ui-audit-20261115/evidence/actual-1080-settings.png) |

## 验证

- `pnpm exec electron-vite build --outDir temp/ui-audit-20261115/build` 通过。依赖的 `use client` 指令出现打包提示。
- `pnpm typecheck`、`pnpm lint` 通过。
- 在独立 Electron 实例打开 15 个模块的两档实际窗口，并检查更多面板、命令面板、首页编辑、笔记编辑模式、待办编辑、英语复习和精读、账单明细、简报展开、媒体批量、密码库表单、聊天和沉浸控制等状态。所测页面未发现整页横向溢出或控件重叠。不同区域各自滚动的场景包括笔记编辑、聊天和设置外观面板。
- 在首页、笔记、待办、英语、智能助手、设置和媒体库抽查了四种风格的浅深色组合。部分详细状态截图使用渲染区尺寸覆盖，原生窗口按钮未捕获。两档实际窗口另行复核了标题栏搜索。
- 本次使用样本数据观察界面与操作路径，未做真实 AI 生成、邮箱授权或浏览器自动填充的端到端测试。媒体库搜索的当前行为来自设计规定的首页仅显示未分组素材，扩展搜索范围需要同步文档。产品源码和业务数据未修改。
